## 💻 Running Locally

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ahmed-Elzaher/Ahmed-Elzaher.github.io.git
   cd Ahmed-Elzaher.github.io
   ```

2. **Open with Live Server (VS Code):**
   * Right-click on `index.html` and select **Open with Live Server**.

3. **Or run with any local static server:**
   ```bash
   # Using npx serve
   npx serve .

   # Or Python
   python -m http.server 3000
   ```
